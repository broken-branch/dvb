# dvb cockpit UI

React + TypeScript + Vite single-page app. The build produces one inlined `dist/index.html`;
the Rust desk (`crates/dvb-desk`) embeds `ui/dist` and serves it on loopback, so rebuild before
building or packaging `dvb`. The code map for agents is [../docs/map/ui.md](../docs/map/ui.md).

Build, test, lint, browser checks and local development commands are in
[the testing guide](../docs/testing.md#before-a-pr).

The app talks to the authenticated desk's `/api` (JSON) and `/events` (SSE).
Tests use fixed engine JSON fixtures typed by `src/api/schema.ts`, which is generated by
`scripts/gen-contracts.sh`; never edit it by hand.
